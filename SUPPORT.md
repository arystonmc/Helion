# Support for Helion

Need help with Helion or encountered a problem? Here is how to get support.

## Getting Help

- **Crash Helper:** Paste your crash report into the [crash helper](https://lureid.com/support/crash) on the Aryston website; it recognises known problems and shows the fix.
- **Compatibility List:** Check which mods, shaders and resource packs work with Helion on the [compatibility page](https://lureid.com/mods/helion/compatibility).
- **Documentation & Features:** Check the [Helion Feature Guide](docs/FEATURES.md).
- **Issue Tracker:** If you found a bug or have a suggestion, search existing issues first on our [GitHub Issues](https://github.com/arystonmc/Helion/issues).

## Reporting Bugs

When filing an issue, please include:
1. Minecraft version, NeoForge version, and Helion version.
2. Your GPU model and graphics driver version.
3. The latest game log file (`logs/latest.log`) uploaded via a paste service like [mclo.gs](https://mclo.gs).
4. Steps to reproduce the problem and screenshots if relevant.

Please use our structured [Bug Report Template](https://github.com/arystonmc/Helion/issues/new?template=bug_report.yml).
